# Campo El Rosario v9.02 — Icon System Fix

Campo v9.02 preserves the local/offline data model and the Record & Review workflow from v9.01, while replacing the inconsistent legacy icons with one approved transparent icon library.

## Included

- Central `icon-library.js` registry.
- 87 approved icons in 24, 32, 48, 64 and 160 px exports.
- Transparent PNG assets for navigation, surveys, events, rain, herd, demo, backup, reports, settings and KPI.
- Definitive pasture-condition icons: Muy bueno, Bueno, Regular, Malo and Anegado.
- Definitive animal-load icons: Baja, Adecuada, Alta, Sobrecarga and Crítica.
- Updated navigation, Registrar, event history, rainfall KPI, lot condition/load details, demo controls, backup and KPI cards.
- Existing storage keys preserved: `campo-el-rosario-v2` and `campo-el-rosario-demo-v1`.

See `CHANGELOG.md`, `DEPLOYMENT.md` and `docs/DEPLOYMENT-STATUS.md`.
