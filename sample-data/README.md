# Datos de demostración

Estos archivos contienen el mismo escenario ficticio precargado en el MVP y sirven para probar importación y exportación sin utilizar información real.

- `inventario-julio-2026.csv`: inventario completo por lote y categoría.
- `eventos-julio-2026.csv`: movimientos y eventos del mes.

La aplicación almacena la información real únicamente en el navegador durante esta etapa local del MVP.
