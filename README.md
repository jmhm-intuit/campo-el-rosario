# Campo El Rosario v10.01

Campo v10.01 is a local-first PWA for cattle and paddock management. This release focuses on **Field First** usability: a simple one-lot-at-a-time survey flow for non-technical field users, while preserving detailed management, events, herd balance, rainfall, history, and animated maps.

## Local persistence

- Real workspace: `campo-el-rosario-v2`
- Demo workspace: `campo-el-rosario-demo-v1`

No cloud account or data migration is required.

## Primary field flow

1. Open **Registrar**.
2. Choose **Comenzar carga simple**.
3. Confirm or adjust one lot at a time.
4. Save and continue later at any point.
5. Finish the survey; management review can validate discrepancies afterward.
