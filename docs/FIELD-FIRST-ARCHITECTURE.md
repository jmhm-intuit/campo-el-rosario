# Campo v10.01 — Field First architecture

## Goal

Make the field survey usable by non-technical and senior users while preserving the existing local-data model and advanced management tools.

## Simple field workflow

1. Date and projected starting point.
2. One lot per screen.
3. Family-level quantities: Vacas, Terneros/as, Toros, Vaquillonas and Novillos.
4. Explicit condition buttons.
5. Quick actions: Sin cambios, Lote vacío and No observado.
6. Automatic local draft saving.
7. Final summary and pending management review.

## Advanced workflow

The existing detailed lot editor remains available for subcategories, birth years, notes and historical editing.

## Map behavior

- Inicio uses the exact whole-ranch bounds shared with the dedicated map view.
- Summary interaction is locked by default so one-finger gestures scroll the page.
- The user explicitly activates map interaction to pan or zoom.
- `Todo` resets to the complete establishment.
